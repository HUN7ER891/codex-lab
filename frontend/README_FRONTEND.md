# Runway Rush Frontend

This folder now contains a lightweight browser game inspired by classic airport control simulations.

## Getting started

1. Open `index.html` in a modern browser. No build step is required.
2. Click **Start new shift** to spawn aircraft.
3. Click an aircraft to select it, then use `L` (land) or `H` (hold) commands to manage the traffic flow.

## Gameplay overview

- Aircraft spawn at the edges of the radar scope and fly toward the runway.
- Un-cleared aircraft will automatically enter a holding pattern when they reach the approach fix.
- Clear aircraft to land once separation is safe; landed aircraft taxi off the runway and increase your score.
- Avoid collisions and runway incursions. Three strikes end the session.

Feel free to replace the static assets with a full framework build if you want to grow the prototype into a larger project.
